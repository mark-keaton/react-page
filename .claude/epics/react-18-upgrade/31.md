### Migration Guide Content
```markdown
# Migrating from ReactPage 5.x to 6.0

## Requirements
- React 18.0 or higher (was: React 16.14+)
- Node.js 20+ (recommended)

## Breaking Changes

### React Version
ReactPage 6.0 requires React 18+. If you're still on React 16 or 17:
- Option 1: Upgrade to React 18 (recommended)
- Option 2: Stay on ReactPage 5.x (security fixes only)

### Data Format
**No changes required.** Existing content works without modification.
The Slate data format is unchanged between versions.

## Upgrade Steps
1. Update your React version to 18+
2. Update ReactPage packages to 6.0.0
3. Run `npm install` / `yarn install`
4. Test your application

## Troubleshooting
[Common issues and solutions]
```
