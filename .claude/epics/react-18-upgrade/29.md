# Task: Update all peerDependencies to React 18+

## Description

Update the `peerDependencies` in all ReactPage packages to require React 18.0 or higher. This is the breaking change that defines ReactPage 6.0.

## Acceptance Criteria

- [ ] All packages with React peerDependency updated to `">= 18.0"`
- [ ] react-dom peerDependency also updated to `">= 18.0"`
- [ ] No packages left with React 16.14 requirement
- [ ] Build succeeds
- [ ] Yarn install completes without peer dependency warnings

## Technical Details

### Packages to Update

Find all packages with React peer dependencies:
```bash
grep -r '"react":' packages/*/package.json
```

Expected packages:
- `packages/editor/package.json`
- `packages/plugins/content/slate/package.json`
- `packages/plugins/content/image/package.json`
- `packages/plugins/content/video/package.json`
- `packages/plugins/content/spacer/package.json`
- `packages/plugins/content/divider/package.json`
- `packages/plugins/content/html5-video/package.json`
- `packages/plugins/layout/background/package.json`
- `packages/react-admin/package.json`

### Change Required
```json
// Before:
"peerDependencies": {
  "react": ">= 16.14",
  "react-dom": ">= 16.14"
}

// After:
"peerDependencies": {
  "react": ">= 18.0",
  "react-dom": ">= 18.0"
}
```

### Verification
```bash
# Check all peerDependencies are updated
grep -r '"react":' packages/*/package.json | grep -v "18.0"
# Should return empty
```
