# Task: Replace slate-react-presentation with native read-only

## Description

Replace the `slate-react-presentation` package (v0.1.1, unmaintained) with native `slate-react` read-only mode. This package is unlikely compatible with Slate 0.120 and using native read-only is the recommended approach.

## Acceptance Criteria

- [ ] `slate-react-presentation` removed from dependencies
- [ ] `ReadOnlySlate.tsx` updated to use native slate-react
- [ ] Read-only rendering works correctly
- [ ] No visual regressions in read-only mode
- [ ] Build succeeds

## Technical Details

### Current Implementation
```typescript
// packages/plugins/content/slate/src/components/ReadOnlySlate.tsx
import { SlateReactPresentation } from 'slate-react-presentation';
// Uses third-party package for read-only rendering
```

### New Implementation
```typescript
import { useMemo } from 'react';
import { createEditor } from 'slate';
import { Slate, Editable, withReact } from 'slate-react';

const ReadOnlySlate = (props: SlateProps) => {
  const editor = useMemo(() => withReact(createEditor()), []);

  return (
    <Slate editor={editor} initialValue={props.data.slate}>
      <Editable
        readOnly
        renderElement={renderElement}
        renderLeaf={renderLeaf}
      />
    </Slate>
  );
};
```
