# Task: Slate upgrade phases 1-2 (0.78 → 0.99)

## Description

Upgrade Slate packages from 0.78/0.79 to 0.99.x. This is the maximum version that still supports React 16.14+. Includes required code changes for breaking changes in 0.94 and 0.95.

### Code Changes

**1. hotkeyHooks.ts (Phase 1 - v0.94 breaking change)**
```typescript
// File: packages/plugins/content/slate/src/components/hotkeyHooks.ts
// Change: editor.insertText('
') → editor.insertSoftBreak()

// Before (around line 50):
if (isHotkey('shift+enter', event)) {
  event.preventDefault();
  editor.insertText('
');
  return true;
}

// After:
if (isHotkey('shift+enter', event)) {
  event.preventDefault();
  editor.insertSoftBreak();
  return true;
}
```

**2. SlateProvider.tsx (Phase 2 - v0.95 breaking change)**
```typescript
// File: packages/plugins/content/slate/src/components/SlateProvider.tsx
// Change: <Slate value={...}> → <Slate initialValue={...}>

// Before (around line 67-74):
<Slate
  editor={editor}
  value={initialValue}
  onChange={onChange}
>

// After:
<Slate
  editor={editor}
  initialValue={initialValue}
  onChange={onChange}
>
```
