# Task: Slate upgrade phases 1-2 (0.78 → 0.99)

## Description

Upgrade Slate packages from 0.78/0.79 to 0.99.x. This is the maximum version that still supports React 16.14+. Includes required code changes for breaking changes in 0.94 and 0.95.

## Acceptance Criteria

- [x] Slate packages updated to ^0.94.1/^0.99.0/^0.100.0 in package.json
- [x] `hotkeyHooks.ts` updated to use `insertSoftBreak()`
- [x] `SlateProvider.tsx` updated: value prop renamed to initialValue
- [x] Build succeeds
- [ ] Basic editor functionality works (manual test - pending user verification)

### Code Changes

**1. hotkeyHooks.ts (Phase 1 - v0.94 breaking change)**
```typescript
// File: packages/plugins/content/slate/src/components/hotkeyHooks.ts
// Change: editor.insertText('
') → editor.insertSoftBreak()

// Before (around line 50):
if (isHotkey('shift+enter', event)) {
  event.preventDefault();
  editor.insertText('
');
  return true;
}

// After:
if (isHotkey('shift+enter', event)) {
  event.preventDefault();
  editor.insertSoftBreak();
  return true;
}
```

**2. SlateProvider.tsx (Phase 2 - v0.95 breaking change)**
```typescript
// File: packages/plugins/content/slate/src/components/SlateProvider.tsx
// Change: <Slate value={...}> → <Slate initialValue={...}>

// Before (around line 67-74):
<Slate
  editor={editor}
  value={initialValue}
  onChange={onChange}
>

// After:
<Slate
  editor={editor}
  initialValue={initialValue}
  onChange={onChange}
>
```

## Implementation Notes

The original task specified Slate 0.99.0, but this version does not exist for the `slate` core package. The actual available versions are:
- `slate`: ^0.94.1 (last stable before 0.100.0 jump)
- `slate-react`: ^0.99.0 (last version supporting React 16.14+, requires React >=16.8.0)
- `slate-hyperscript`: ^0.100.0 (earliest available in 0.100.x range)

Key findings:
- `slate-react@0.100.0` requires React >=18.2.0
- `slate-react@0.99.0` supports React >=16.8.0
- This upgrade maintains React 16.14+ compatibility

Additional fix required:
- `listUtils.ts`: Added `Element.isElement()` type guard for `Editor.isInline()` call (Slate 0.94+ type stricter)
