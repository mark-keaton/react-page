# Task: Write final recommendation

## Description

Write the final recommendation document that synthesizes all research into a clear, actionable decision. This is the primary deliverable of the epic.

## Acceptance Criteria

- [ ] Clear recommendation statement ("Do X because Y")
- [ ] Executive summary for quick decision-making
- [ ] Detailed rationale referencing research findings
- [ ] Risk assessment for chosen path
- [ ] Implementation roadmap outline for chosen path
- [ ] Stakeholder-ready format

## Technical Details

**Document structure:**

1. **Executive Summary** (1 paragraph)
   - The recommendation
   - Key reasons
   - Estimated effort

2. **Recommendation**
   - Clear statement of chosen path
   - Why this path wins on priority criteria

3. **Analysis Summary**
   - Key findings from each research task
   - Comparison matrix highlights

4. **Risk Assessment**
   - Risks of chosen path
   - Mitigations
   - Risks of NOT choosing the alternative

5. **Implementation Roadmap** (high-level)
   - Phases for chosen path
   - Key milestones
   - Resource requirements

6. **Appendix**
   - Links to all research documents
   - Data sources

**Output format:**
Create `.claude/epics/tiptap-vs-slate-upgrade/RECOMMENDATION.md` with full document
