# Task: React-DnD Compatibility

## Description

Fix React-DnD compatibility with Next.js and Vite. This is the highest-risk task in the epic. First attempt: upgrade react-dnd to latest. If that fails to resolve SSR issues, evaluate replacing with dnd-kit.

## Acceptance Criteria

- [ ] Drag-and-drop works in standard React app
- [ ] Drag-and-drop works in Next.js 14+ (SSR)
- [ ] Drag-and-drop works in Vite 5+
- [ ] All E2E drag-drop tests pass (14 tests)
- [ ] No hydration errors in SSR environments
- [ ] Touch device support maintained

## Technical Details

### Current State
- react-dnd version: check package.json
- Known issue: SSR compatibility with Next.js
- Known issue: Vite bundling issues

### Approach 1: Upgrade react-dnd
```bash
# Update to latest react-dnd
yarn add react-dnd@latest react-dnd-html5-backend@latest
```

Check for:
- SSR-safe initialization
- Dynamic imports for backend
- Hydration-safe patterns

### Approach 2: Replace with dnd-kit (if Approach 1 fails)
dnd-kit advantages:
- Built for SSR from the start
- Better accessibility
- More flexible API
- Active maintenance

Migration would require:
- Replace DndProvider with DndContext
- Update useDrag/useDrop to dnd-kit equivalents
- Update drag preview handling

- All drag-drop related components
