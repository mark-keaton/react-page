# Task: Babel + TypeScript Upgrade

## Description

Upgrade Babel from 7.2.x to 7.28.x and TypeScript from 4.8.x to 5.7.x. This is the foundation task that enables all subsequent upgrades. Must be done first as other packages depend on these build tools.

## Acceptance Criteria

- [ ] All @babel/* packages upgraded to 7.28.x
- [ ] TypeScript upgraded to 5.7.x
- [ ] Deprecated Babel plugins removed/replaced
- [ ] tsconfig.json updated for TS 5.x features
- [ ] Build completes without errors
- [ ] All 541+ tests pass (Jest + Playwright)

## Technical Details

### Babel Packages to Update
```
@babel/cli: 7.2.0 → 7.28.x
@babel/core: 7.2.0 → 7.28.x
@babel/plugin-proposal-class-properties: 7.2.1 → remove (now standard)
@babel/plugin-transform-modules-commonjs: 7.2.0 → 7.28.x
@babel/preset-env: 7.2.0 → 7.28.x
@babel/preset-react: 7.0.0 → 7.28.x
@babel/preset-typescript: 7.18.6 → 7.28.x
```

### TypeScript Changes
- Update `typescript` to 5.7.x
- Update `ts-jest` to compatible version
- Review tsconfig.json for new options
- Fix any new type errors (TS 5 is stricter)

### Files Affected
- package.json (root)
- packages/*/package.json (if local babel configs)
- babel.config.js or .babelrc
- tsconfig.json
- config/tsconfig.*.json
