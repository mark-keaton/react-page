# Task: React-DnD Compatibility

## Description

Fix React-DnD compatibility with Next.js and Vite. This is the highest-risk task in the epic. First attempt: upgrade react-dnd to latest. If that fails to resolve SSR issues, evaluate replacing with dnd-kit.

## Completion Summary

Successfully upgraded react-dnd from v15.1.2 to v16.0.1 with Next.js compatibility.

### Changes Made

1. **Updated react-dnd packages** (packages/editor/package.json):
   - `react-dnd`: ^15.1.2 -> ^16.0.1
   - `react-dnd-html5-backend`: ^15.1.2 -> ^16.0.1

2. **Updated Next.js configuration** (examples/next.config.js):
   - Added `transpilePackages` for ESM-only react-dnd packages and all @react-page/* packages
   - Added `experimental.esmExternals: 'loose'` for ESM/CJS interop

### Key Technical Details

React-dnd v16+ is ESM-only, which caused issues with Next.js consuming the library's CommonJS build. The solution was to:
1. Use `transpilePackages` to ensure Next.js properly transpiles the ESM-only dependencies
2. Enable `esmExternals: 'loose'` to allow mixed ESM/CJS module resolution

No code changes were required to the drag-drop implementation - the existing react-dnd API (useDrag, useDrop, DragPreviewImage) is unchanged in v16.
