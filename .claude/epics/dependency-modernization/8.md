# Task: Integration Testing

## Description

Create example applications with Next.js 14+ and Vite 5+ to validate ReactPage works correctly in modern build environments. This is the final validation that all dependency updates achieve the stated goals.

## Acceptance Criteria

- [ ] Next.js 14+ example app created
- [ ] Next.js example builds without errors
- [ ] Next.js example runs with SSR working
- [ ] Vite 5+ example app created
- [ ] Vite example builds without errors
- [ ] Vite example runs with HMR working
- [ ] Drag-drop works in both environments
- [ ] No hydration errors in Next.js

## Technical Details

### Next.js Example
Create in `examples/nextjs/`:
```bash
npx create-next-app@latest examples/nextjs --typescript
cd examples/nextjs
yarn add @react-page/editor @react-page/plugins-slate @react-page/plugins-image
```

Validate:
- SSR renders correctly
- Hydration completes without errors
- Drag-drop works
- All editor features work

### Vite Example
Create in `examples/vite/`:
```bash
npm create vite@latest examples/vite -- --template react-ts
cd examples/vite
yarn add @react-page/editor @react-page/plugins-slate @react-page/plugins-image
```

Validate:
- Dev server starts
- HMR works
- Production build succeeds
- Editor features work

### Files to Create
```
examples/
  nextjs/
    package.json
    pages/index.tsx (or app/page.tsx)
    components/Editor.tsx
  vite/
    package.json
    src/App.tsx
    src/Editor.tsx
```

### Integration Checklist
For each example app:
- [ ] Editor loads
- [ ] Can add cells
- [ ] Can drag-drop cells
- [ ] Can edit text (Slate)
- [ ] Can add images
- [ ] Can save/load value
