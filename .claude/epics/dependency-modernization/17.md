# Task: MUI + Emotion Updates

## Description

Update Material-UI (MUI) from 5.10.x to 5.18.x and Emotion packages to latest. This is a minor version update within MUI 5, which should be relatively safe.

## Acceptance Criteria

- [ ] @mui/material updated to 5.18.x
- [ ] @mui/icons-material updated to 5.18.x
- [ ] @emotion/react updated to latest
- [ ] @emotion/styled updated to latest
- [ ] All UI components render correctly
- [ ] All E2E tests pass
- [ ] No visual regressions

## Technical Details

### Packages to Update
```
@mui/material: 5.10.12 → 5.18.x
@mui/icons-material: 5.10.9 → 5.18.x
@mui/styles: 5.10.10 → 5.18.x (if used)
@emotion/react: 11.10.5 → 11.14.x
@emotion/styled: 11.10.5 → 11.14.x
@emotion/cache: 11.10.5 → 11.14.x
@emotion/server: 11.10.0 → 11.11.x
```

### Note on MUI v7
MUI v7 is available but OUT OF SCOPE for this task. The v5 → v7 migration is significant and would require its own epic. We're staying on 5.x.

### Files Affected
- package.json (root and packages)
- Any component using MUI components
- Theme configuration files

- Check toolbar buttons
- Check dialogs and modals
- Check form inputs
