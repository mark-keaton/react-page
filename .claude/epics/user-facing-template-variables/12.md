# Task: Create VariablePicker shared component

## Description

Build a reusable React component that displays available template variables in a dropdown picker. This component will be used by plugin controls to let content editors insert variables into text fields.

- [ ] MUI Autocomplete-based dropdown component

- [ ] Keyboard accessible (can navigate with arrow keys, select with Enter)

- [ ] Styled consistently with existing plugin UIs
