# Task: Update Cards plugin controls with variable picker integration

## Description

Integrate the VariablePicker component into the Cards plugin's control panel, allowing content editors to insert variables into the title, subtitle, and body field mappings.

## Acceptance Criteria

- [ ] "Insert Variable" button added next to title, subtitle, and body text inputs
- [ ] Clicking button opens VariablePicker dropdown
- [ ] Selecting a variable inserts `{{fieldKey}}` into the text input
- [ ] Variables can be mixed with static text (e.g., "Price: {{price}}")
- [ ] Field mapping type updated to accept string with variables (not just field key)
- [ ] UI clearly indicates when a field contains variables

## Technical Details

**Files:**
- `packages/plugin-cards/src/DataCardsControls.tsx`
