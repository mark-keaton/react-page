# Task: Implement variable utility functions

## Description

Create utility functions in `@react-page-data/core` for working with template variables. These functions handle variable extraction, resolution, and filtering exposed fields from templates.

## Acceptance Criteria

- [ ] `resolveVariables(text: string, row: Record<string, unknown>): string` - Replaces `{{key}}` with row values
- [ ] `extractVariables(text: string): string[]` - Returns list of variable keys found in text

- [ ] Functions handle edge cases (null values, missing keys, nested braces)
- [ ] Functions are exported from package index

## Technical Details

**File:** `packages/core/src/variables.ts` (new file)

```typescript
const VARIABLE_REGEX = /\{\{(\w+)\}\}/g;

export function resolveVariables(text: string, row: Record<string, unknown>): string {
  return text.replace(VARIABLE_REGEX, (_, key) => {
    const value = row[key];
    return value != null ? String(value) : '';
  });
}

export function extractVariables(text: string): string[] {
  const matches = text.matchAll(VARIABLE_REGEX);
  return [...new Set([...matches].map(m => m[1]))];
}

export function getExposedVariables(template: Template): FieldDefinition[] {
  return template.fields.filter(f => f.exposeAsVariable === true);
}
```
