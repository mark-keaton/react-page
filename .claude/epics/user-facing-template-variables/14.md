# Task: Update Cards renderer to resolve variables per-row

## Description

Modify the Cards plugin renderer to resolve template variables in field mappings against each row's data. This enables dynamic content where each card displays its own data values.

## Acceptance Criteria

- [ ] Title, subtitle, and body fields resolve `{{fieldKey}}` to actual values
- [ ] Each card receives its own row context for variable resolution
- [ ] Variables resolve correctly for all data types (string, number, boolean)
- [ ] Missing/null values render as empty string (no "undefined" text)
- [ ] Text without variables renders unchanged (backwards compatible)
- [ ] No visible performance impact with many cards

## Technical Details

**File:** `packages/plugin-cards/src/DataCardsRenderer.tsx`

**Changes:**
1. Import `resolveVariables` from `@react-page-data/core`
2. In the card mapping loop, call `resolveVariables(fieldMapping.title, row)` etc.
3. Memoize resolved values if performance concerns arise

```typescript
// Before
const title = row[fieldMapping.title];

// After
const title = fieldMapping.title
  ? resolveVariables(fieldMapping.title, row)
  : '';
```
