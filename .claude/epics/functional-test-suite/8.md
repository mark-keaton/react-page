### Key Test Scenarios

**useCell Hook**
- Returns cell data for valid ID
- Returns undefined for invalid ID
- Updates when cell content changes
- Memoizes correctly (no unnecessary rerenders)

**useRow Hook**
- Returns row data for valid ID
- Returns cells array
- Updates when row structure changes

**useEditor Hook**
- Provides addCell function
- Provides removeCell function
- Provides getValue function
- Provides setValue function

**Serialization**
- Serialize empty editor
- Serialize editor with single cell
- Serialize editor with multiple rows
- Serialize editor with nested cells
- Handle circular references gracefully

**Deserialization**
- Load valid JSON
- Handle malformed JSON gracefully
- Handle missing fields with defaults
- Handle unknown plugin types

**Migrations**
- Migrate from v0 to current
- Handle missing version field
- Preserve custom data through migration
- Migration is idempotent

### Testing Hooks Pattern
```typescript
import { renderHook } from '@testing-library/react-hooks';
import { Provider } from 'react-redux';

describe('useCell', () => {
  it('returns cell data', () => {
    const wrapper = ({ children }) => (
      <Provider store={createTestStore()}>{children}</Provider>
    );

    const { result } = renderHook(() => useCell('cell-1'), { wrapper });

    expect(result.current.plugin).toBe('slate');
  });
});
```
