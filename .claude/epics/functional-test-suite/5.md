# Task: E2E Slate Editor Tests

## Description

Write E2E tests for the Slate rich text editor integration, covering text input, formatting, lists, links, and selection behavior.

## Acceptance Criteria

- [x] Basic text input and editing
- [x] Bold, italic, underline formatting via toolbar
- [x] Bold, italic, underline via keyboard shortcuts
- [x] Heading levels (H1-H6)
- [x] Bullet lists and numbered lists
- [x] Links: add, edit, remove
- [x] Undo/redo within Slate editor
- [x] Copy/paste plain text
- [x] Selection and cursor behavior
- [x] Minimum 15 test cases (37 tests created)

## Technical Details

### Test File Structure
```
e2e/tests/
  slate/
    text-input.spec.ts      # Basic typing (8 tests)
    formatting.spec.ts      # Bold, italic, etc. (12 tests)
    lists.spec.ts           # Bullet, numbered (10 tests)
    links.spec.ts           # Link operations (10 tests)
```

### Key Test Scenarios

**Text Input**
- Type text into empty Slate cell
- Edit existing text
- Delete text (backspace, delete key)
- Multi-line text entry

**Formatting**
- Apply bold via toolbar button
- Apply bold via Ctrl/Cmd+B
- Apply italic via toolbar/shortcut
- Apply underline via toolbar/shortcut
- Remove formatting
- Multiple formats on same text

**Lists**
- Create bullet list
- Create numbered list
- Indent/outdent list items
- Convert between list types
- Exit list with Enter on empty item

**Links**
- Add link to selected text
- Edit existing link
- Remove link
- Link opens in new tab (verify href)

**Selection**
- Select word with double-click
- Select paragraph with triple-click
- Keyboard selection (Shift+Arrow)
- Select all (Ctrl/Cmd+A)

### Slate-Specific Considerations
- Slate uses contenteditable, requires careful selector strategy
- Use `[data-slate-editor]` to locate editor
- Use `[data-slate-node="text"]` for text nodes
- Toolbar buttons should have accessible names
