# Task: E2E Core Editor Tests

## Description

Write comprehensive E2E tests for core editor functionality including initialization, cell/row CRUD operations, and drag-and-drop interactions.

## Acceptance Criteria

- [ ] Editor initialization tests (empty, pre-populated, custom plugins)
- [ ] Cell operations: add, delete, duplicate
- [ ] Row operations: add, delete, move up/down
- [ ] Drag-and-drop: move cell within row, move cell to different row
- [ ] Cell resize operations
- [ ] Undo/redo for all operations
- [ ] Editor state serialization verified after each operation
- [ ] Minimum 15 test cases

## Technical Details

### Test File Structure
```
e2e/tests/
  editor/
    initialization.spec.ts   # Editor loading scenarios
    cell-operations.spec.ts  # Cell CRUD
    row-operations.spec.ts   # Row CRUD
    drag-drop.spec.ts        # DnD interactions
    resize.spec.ts           # Cell resizing
```

### Key Test Scenarios

**Initialization**
- Editor renders with default config
- Editor renders with custom plugins array
- Editor handles empty initial value
- Editor loads pre-populated content correctly
- Read-only mode prevents editing

**Cell Operations**
- Add cell from plugin drawer
- Delete cell via context menu/button
- Duplicate cell
- Cell selection highlights correctly

**Drag-and-Drop**
- Drag cell to reorder within row
- Drag cell to different row
- Drag row to reorder
- Cancel drag operation
- Visual feedback during drag

**Resize**
- Resize cell wider
- Resize cell narrower
- Resize respects minimum width
- Resize affects adjacent cells correctly

### Testing Strategy
- Use `data-testid` attributes where possible
- Fall back to role-based selectors
- Avoid CSS class selectors (brittle)
- Each test starts with fresh editor state
