### Key Test Scenarios

**Image Plugin**
- Add image cell from drawer
- Set image URL via settings
- Change alignment (left, center, right)
- Delete image cell

**Video Plugin (Embed)**
- Add video cell
- Enter YouTube/Vimeo URL
- Video iframe renders
- Remove video cell

**Spacer Plugin**
- Add spacer cell
- Adjust height via settings
- Verify rendered height matches setting

**Divider Plugin**
- Add divider cell
- Divider renders as horizontal line
- Remove divider

**Background Plugin (Layout)**
- Add cell with background
- Set background color
- Set background image URL
- Verify background renders on cell

**Plugin Drawer**
- Open plugin drawer
- All plugins visible
- Search/filter plugins (if available)
- Click plugin adds to editor

### Plugin Settings Testing
- Each plugin has settings panel
- Settings changes reflect immediately
- Settings persist after save/reload
