# Task: E2E Plugin Tests

## Description

Write E2E tests for all bundled plugins: image, video, spacer, divider, html5-video, and the background layout plugin.

## Acceptance Criteria

- [ ] Image plugin: add, configure alignment, remove
- [ ] Video plugin: add with URL, playback controls visible
- [ ] HTML5 Video plugin: add, configure source
- [ ] Spacer plugin: add, adjust height
- [ ] Divider plugin: add, renders correctly
- [ ] Background plugin: set color, set image
- [ ] Plugin drawer shows all available plugins
- [ ] Plugin settings UI accessible and functional
- [ ] Minimum 15 test cases

## Technical Details

### Test File Structure
```
e2e/tests/
  plugins/
    image.spec.ts           # Image plugin
    video.spec.ts           # Video embed plugin
    html5-video.spec.ts     # HTML5 video plugin
    spacer.spec.ts          # Spacer plugin
    divider.spec.ts         # Divider plugin
    background.spec.ts      # Background layout plugin
    plugin-drawer.spec.ts   # Plugin selection UI
```

### Key Test Scenarios

**Image Plugin**
- Add image cell from drawer
- Set image URL via settings
- Change alignment (left, center, right)
- Delete image cell

**Video Plugin (Embed)**
- Add video cell
- Enter YouTube/Vimeo URL
- Video iframe renders
- Remove video cell

**Spacer Plugin**
- Add spacer cell
- Adjust height via settings
- Verify rendered height matches setting

**Divider Plugin**
- Add divider cell
- Divider renders as horizontal line
- Remove divider

**Background Plugin (Layout)**
- Add cell with background
- Set background color
- Set background image URL
- Verify background renders on cell

**Plugin Drawer**
- Open plugin drawer
- All plugins visible
- Search/filter plugins (if available)
- Click plugin adds to editor

### Plugin Settings Testing
- Each plugin has settings panel
- Settings changes reflect immediately
- Settings persist after save/reload
