# Task: Integration Redux Tests

## Description

Write Jest integration tests for Redux state management: reducers, action creators, and selectors for editor value, focus, and hover state.

## Acceptance Criteria

- [ ] Value reducer tests: all action types covered
- [ ] Focus reducer tests: focus/blur/selection actions
- [ ] Hover reducer tests: hover enter/leave actions
- [ ] Action creator tests: correct action shapes
- [ ] Selector tests: derived state calculations
- [ ] Undo/redo middleware tests
- [ ] Code coverage 80%+ for Redux modules
- [ ] Minimum 40 test cases

## Technical Details

### Key Test Scenarios

**Value Reducer**
- ADD_CELL action
- REMOVE_CELL action
- MOVE_CELL action
- UPDATE_CELL_CONTENT action
- RESIZE_CELL action
- ADD_ROW action
- REMOVE_ROW action
- MOVE_ROW action
- SET_VALUE action (full state replacement)

**Focus Reducer**
- FOCUS_CELL action
- BLUR_CELL action
- SET_EDIT_MODE action

**Hover Reducer**
- HOVER_CELL action
- LEAVE_CELL action

**Selectors**
- getCellById selector
- getRowById selector
- getCellsByRow selector
- getFocusedCell selector
- getEditMode selector

**Undo/Redo**
- Undo reverts last action
- Redo reapplies undone action
- Undo stack has correct depth
- Some actions are not undoable (focus/hover)

### Testing Pattern
```typescript
describe('valueReducer', () => {
  it('should add cell to row', () => {
    const initialState = createTestState();
    const action = addCell({ rowId: 'row-1', plugin: 'slate' });
    const newState = valueReducer(initialState, action);

    expect(newState.rows['row-1'].cells).toHaveLength(2);
  });
});
```
