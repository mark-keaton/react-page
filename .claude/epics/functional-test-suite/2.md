# Task: Playwright Infrastructure Setup

## Description

Install and configure Playwright for E2E testing in the ReactPage monorepo. Set up the foundational test infrastructure including page objects, fixtures, and dev server integration.

## Acceptance Criteria

- [ ] Playwright installed as dev dependency at project root
- [ ] `playwright.config.ts` configured for monorepo structure
- [ ] Dev server (examples app) starts automatically before tests
- [ ] Base page objects created: EditorPage, CellComponent, RowComponent
- [ ] Test fixtures for common scenarios (empty editor, pre-populated editor)
- [ ] Smoke test verifies editor loads and is interactive
- [ ] `yarn test:e2e` script added to root package.json
- [ ] Tests run successfully against Chromium

## Technical Details

### Installation
```bash
yarn add -D @playwright/test
npx playwright install chromium firefox webkit
```

### Configuration (`playwright.config.ts`)
- Base URL: `http://localhost:3000`
- Web server: `yarn dev` with 60s timeout
- Projects: Chromium (primary), Firefox, WebKit
- Output: `e2e/test-results/`
- Retries: 0 (no flaky tests allowed)

### Directory Structure
```
e2e/
  fixtures/
    editor.fixture.ts      # Common test fixtures
  page-objects/
    editor.page.ts         # EditorPage class
    cell.component.ts      # Cell interactions
    row.component.ts       # Row interactions
    slate.component.ts     # Slate editor interactions
    plugin-drawer.component.ts  # Plugin drawer
  tests/
    smoke.spec.ts          # Basic smoke tests
  playwright.config.ts
```

### Page Object Pattern
```typescript
// e2e/page-objects/editor.page.ts
export class EditorPage {
  constructor(private page: Page) {}

  async goto() { /* navigate to editor */ }
  async addCell(plugin: string) { /* add cell from drawer */ }
  async getCell(index: number) { /* return CellComponent */ }
  async getValue() { /* get serialized editor value */ }
}
```
