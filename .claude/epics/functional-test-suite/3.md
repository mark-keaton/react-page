# Task: GitHub Actions CI Workflow

## Description

Create a GitHub Actions workflow that runs both Jest integration tests and Playwright E2E tests on every PR and push to main. Configure caching, artifact collection, and status checks.

## Acceptance Criteria

- [ ] Workflow triggers on PR and push to main/master
- [ ] Jest tests run with coverage reporting
- [ ] Playwright tests run against Chromium (primary)
- [ ] Firefox and WebKit run as separate optional jobs
- [ ] Dependencies cached (node_modules, Playwright browsers)
- [ ] Failed test artifacts (screenshots, traces) uploaded
- [ ] Total CI duration under 10 minutes
- [ ] PR status checks block merge on test failure

## Technical Details

### Workflow File (`.github/workflows/test.yml`)
```yaml
name: Tests
on:
  push:
    branches: [main, master]
  pull_request:
    branches: [main, master]

jobs:
  jest:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '18'
          cache: 'yarn'
      - run: yarn install --frozen-lockfile
      - run: yarn bootstrap
      - run: yarn test --coverage
      - uses: coverallsapp/github-action@v2
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}

  playwright:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '18'
          cache: 'yarn'
      - run: yarn install --frozen-lockfile
      - run: yarn bootstrap
      - run: yarn build:lib
      - run: npx playwright install --with-deps chromium
      - run: yarn test:e2e
      - uses: actions/upload-artifact@v4
        if: failure()
        with:
          name: playwright-report
          path: e2e/test-results/
```

### Caching Strategy
- Yarn cache: Built-in via `actions/setup-node`
- Playwright browsers: Cached by version in workflow
- Build artifacts: Not cached (rebuilt each run for accuracy)

### Timeout Configuration
- Jest job: 10 minutes max
- Playwright job: 15 minutes max (includes build)
